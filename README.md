# citara-site

Published site for **Citara** — an evidence-first AI visibility (GEO) and agent readiness system.

Live at <https://musaceylan.github.io/citara-site/>.

- `index.html` — the site
- `roadmap.html` — all 23 phases and 459 tasks with their current state
- `shots/` — screenshots captured from a running local instance

This repository holds published output only. It is regenerated from the
application repository with `npm run site:deploy`; edit it there, not here.
